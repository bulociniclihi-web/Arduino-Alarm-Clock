# Arduino Alarm Clock

פרויקט שעון דיגיטלי ושעון מעורר המבוסס על Arduino Uno.

המערכת מציגה את השעה והתאריך באמצעות רכיב RTC מסוג DS1302 ומסך LCD I2C. בנוסף, ניתן להגדיר שעת התראה באמצעות שלושה כפתורים. כאשר מגיע זמן ההתראה, הבאזר מופעל ומוצגת הודעת ALARM על המסך.

## רכיבי המערכת
- Arduino Uno
- RTC DS1302
- LCD I2C 16x2
- 3 Push Buttons
- Buzzer

## הוראות הפעלה
1. במצב הרגיל מוצגים השעה והתאריך ומצב ההתראה על מסך ה-LCD.
2. לחיצה על הכפתור השחור (SET) מתחילה את הגדרת ההתראה.
3. בשלב הראשון מגדירים את השעה באמצעות הכפתור הירוק (UP) והכפתור האדום (DOWN).
4. לחיצה נוספת על SET עוברת להגדרת הדקות.
5. לחיצה נוספת על SET שומרת ומפעילה את ההתראה.
6. כאשר מגיע זמן ההתראה, הבאזר מצלצל ומופיעה הודעת ALARM על המסך.
7. לחיצה על SET בזמן הצלצול מפסיקה ומכבה את ההתראה.
8. לחיצה בו זמנית על UP ו-DOWN מבטלת את ההתראה.
